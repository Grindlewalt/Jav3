# GUI concept mockups

Three standalone HTML mockups to pick a direction for the Jarvis GUI
(backlog item, 2026-07-08). Open each directly in a browser — no build, no
network, fake data throughout.

| File | Direction | One-liner |
|---|---|---|
| `mission-control.html` | Dense ops board | Everything on one screen: status strip, chat, live agent tree, approval queues. For when Jarvis is a system you *operate*. |
| `notebook.html` | Document-first | The project journal is the spine; chat, diffs and runs hang off it. For when Jarvis is a colleague you *collaborate with*. |
| `command-deck.html` | Chat-centric | One big conversation, collapsible context cards on the right, a command palette. For when Jarvis is an assistant you *talk to*. |

All three share the current app palette so the comparison is about layout
and hierarchy, not color.
